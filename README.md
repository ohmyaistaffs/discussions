# OhMyAIStaffs Discussions

This repository hosts the official discussion space for [https://ohmyaistaffs.io/](https://ohmyaistaffs.io/).

## What is OhMyAIStaffs?

OhMyAIStaffs is an AI-focused product website where users can explore and use AI staff/assistant experiences for real tasks.
This discussion repository is the community channel for product updates, support topics, and improvement ideas.

## Installation / Getting Started

### Use the product
1. Go to [https://ohmyaistaffs.io/](https://ohmyaistaffs.io/).
2. Sign in or create an account (if required).
3. Follow the onboarding steps on the site to start using available AI staff features.

### Join discussions (no local installation required)
You can open discussions directly on GitHub to ask questions or share feedback.

### Edit this documentation locally
```bash
git clone https://github.com/ohmyaistaffs/discussions.git
cd discussions
```

## Feedback from Users and Developers

We welcome feedback from both users and developers, including:
- bug reports
- feature requests
- usage questions
- ideas to improve product quality and user experience

Please create a new discussion with clear details so the team can review and respond quickly.
